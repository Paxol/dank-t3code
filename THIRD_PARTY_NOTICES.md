## T3 Code Bar (macOS)

Source: <https://github.com/eliophan/t3code-bar>

This widget is a Linux/DMS port of T3 Code Bar. Its thread status rules, inbox order, previews, usage counting and pricing, and limits layout are ported from that project's Swift sources, and its artwork in `assets/` is copied from it. `tests/canary/` holds that project's canary fixture and golden numbers. It is MIT licensed; the license is in `LICENSE`.

## T3 Code

Source: <https://github.com/pingdotgg/t3code>

Status/sorting behavior was adapted with reference to T3 Code. This widget uses T3 Code identity artwork in `assets/T3Logo.png`, and provider icon artwork in `assets/providers/`. The provider files were copied from the provider icon definitions in the T3 Code app (OpenCode, Cursor, Grok, Kiro, fx, Pi, Muse, and the Antigravity raster logo), with single-color logos recolored to a muted gray for Bar's dark popover. Corresponding upstream references include `apps/web/src/components/Icons.tsx`, `apps/mobile/src/components/ProviderIcon.tsx`, `apps/marketing/public/harnesses/`, and `assets/prod/logo.svg`.
